# Admin UI

React + Vite + TypeScript + Tailwind admin for the Subscription Billing Kit
API. See `docs/ARCHITECTURE.md` at the repo root for the design direction
(§7) and `../api` for the backend this talks to.

```
npm run dev --workspace=web   # http://localhost:5173
```

Set `VITE_API_BASE_URL` (see `.env.example`) if the API isn't at
`http://localhost:3000`.
